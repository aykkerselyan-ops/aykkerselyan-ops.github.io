# rclone-sync

Personal file synchronization tool operated by Ayк Kerselyan.

This application uses rclone to access my own Google Drive
and synchronize selected folders with my own Yandex Disk.
It is for personal use only and is not offered to other users.

Google Drive access is used to list, read, create, update,
and delete files as needed for the synchronization tasks
that I explicitly run.
