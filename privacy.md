# Privacy Policy for rclone-sync

Last updated: 17 October 2026.

rclone-sync is a personal configuration of rclone operated
by Ayk Kerselyan. It is used only with the owner's accounts
and is not offered as a service to other users.

## Data access and use

The application accesses file contents, names, folder
structure, and metadata in the owner's Google Drive
to synchronize selected folders with the owner's
Yandex Disk account.

It can read, create, update, and delete files as required
by the synchronization tasks initiated by the owner.

## Storage and sharing

Files are processed on the owner's computer and stored
in the selected cloud accounts. Local configuration
stores authorization credentials, and local logs may
contain file names and operational details.

Selected files are transferred to Yandex Disk as part
of the requested synchronization. Data is not sold,
used for advertising, or shared with other parties
by this application.

## Control and retention

The owner controls synchronization, file retention,
and deletion in each storage location. Deleting a file
in one location does not necessarily delete every copy.

Google account access can be revoked at any time
through the Google Account security settings.
Local credentials and logs can also be deleted.
